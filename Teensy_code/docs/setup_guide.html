🤖 Setup Teensy 4.0

FranRobots - Maze Navigation Challenge

✅ Código Pronto para Compilar!

Todas as dependências estão configuradas. Siga os passos abaixo para rodar na Teensy.

⚡ Quick Start (5 minutos)

🚀 Opção 1 - Automático (Recomendado)
cd c:\Users\Instrutor\Desktop\franrobots_26-27\Teensy_code .\setup_and_build.ps1 # Ou: setup_and_build.bat

Isso fará tudo automaticamente: baixar dependências, compilar e preparar para upload.

📝 Opção 2 - Manual
pio run -e teensy40 # Download + Compilar pio run -e teensy40 --target=upload # Upload para Teensy pio device monitor -b 115200 # Monitor Serial

📋 Processo Passo-a-Passo

1️⃣ Verificar Pré-requisitos
  • Python 3.x instalado (verificar: python --version)
  • PlatformIO instalado (verificar: pio --version)
  • Teensy Loader instalado
  • Teensy 4.0 conectada via USB
Se faltar algo, execute: pip install platformio
2️⃣ Baixar Dependências
O sistema baixará automaticamente:
  • ✓ Framework Arduino (Teensy Core)
  • ✓ Pololu VL53L0X (sensores ToF)
  • ✓ Adafruit BNO055 (IMU)
  • ✓ Adafruit NeoPixel (LEDs)
  • ✓ Adafruit BusIO e dependências
3️⃣ Compilar Código
pio run -e teensy40
Você verá: ======================== [SUCCESS] Took X.XX seconds ========================
4️⃣ Fazer Upload
pio run -e teensy40 --target=upload

Se pedir: Pressione o botão PROGRAM na Teensy

Resultado esperado: "Programming complete"

5️⃣ Monitorar Serial
pio device monitor -b 115200

Você deve ver:

  • ✓ "Sistema iniciando..."
  • ✓ "Sistema pronto."
  • ✓ "Deus abençoe o round."

🔧 Solução de Problemas

❌
PlatformIO não encontrado
pip install platformio
❌
Teensy não encontrada
• Reconecte a Teensy
• Instale driver Teensy
• Use outro cabo USB
❌
Erro de compilação
pio run -e teensy40 --target=clean pio run -e teensy40
❌
Serial Monitor vazio
• Aguarde 5 segundos
• Verifique baud rate (115200)
• Pressione reset na Teensy
❌
Upload falha
• Pressione botão PROGRAM
• Use Teensy Loader manual
• Reinicie PlatformIO
❌
Dependências faltando
pio lib update pio run -e teensy40

✅ Checklist Final

  • Python 3.x instalado
  • PlatformIO CLI instalado
  • Teensy 4.0 conectada
  • Compilação sem erros
  • Upload bem-sucedido
  • Serial Monitor conectado (115200 baud)
  • Mensagens aparecem no console
  • Sensores respondem
  • Motores giram (teste com levantado)
  • Calibração concluída
